# Agent Events — design kit

Brand and design assets for **Agent Events**.

## Contents

All assets live in [`agentevents-brand-kit/`](agentevents-brand-kit/) — see its
[README](agentevents-brand-kit/README.md) for the full file list, usage notes, and
the web-embed snippet.

In short:

- **SVG** — primary mark (with/without reasoning ring, plus an animated variant),
  light/dark lockups, and favicon sources
- **PNG** — raster exports in [`agentevents-brand-kit/png/`](agentevents-brand-kit/png/)
- **ICO** — multi-resolution `favicon.ico` for legacy browsers
- **Preview** — open [`agentevents-brand-kit/preview.html`](agentevents-brand-kit/preview.html)
  to view the assets

## Brand basics

The mark reads an agent run as an append-only **stream of events**: three growing
nodes flow into a forward arrowhead, the lead node carrying a concentric "reasoning"
ring as the AI cue. Wordmark is Space Grotesk Medium (outlined to paths, no font
dependency). Primary teal: `#0F6E56` / `#1D9E75` / `#5DCAA5` / `#9FE1CB`.
